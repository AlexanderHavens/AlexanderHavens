This is a repository for MATLAB code I wrote throughout my time at University of Colorado at Boulder.
It's not all of it, a good chunk of the code I wrote was because I didn't feel like doing matrix math and MATLAB was right there.
Each individual assignment or project is listed in their own branch for organization. I didn't name files during my time with global all file organization in mind.
Also, considering I no longer have access to MATLAB, and both RunMat and Octave have some minor quibbles with the code, I can't confirm it all still works exactly as intended.
It's been a very long time since I actually ran any of this on matlab (3+ years in some cases, or even longer).
I'm just not willing to debug all of it to get it to work on open source software, since in a realistic setting I'd just be using MATLAB again. 

My favorite Projects are the Aerodynamics (AD branches for short). It was one of my favorite classes in the entire program, and I'm particularly proud of those projects.
Working with my friends an colleagues on them was a ton of fun. Also I just love aerodynamics. Maybe I'm insane but looking at those wings (and engines, in some cases) I can just hear them roar.
